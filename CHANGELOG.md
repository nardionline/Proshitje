# Changelog

## WPF Prototype 2.0 — 2026-10-22
- Krijuar projekt i veçantë WPF .NET Framework 4.8 x86.
- Ndërfaqe e re për katalogun dhe faturën.
- Shtuar paraqitja e njësisë në kartat e produkteve dhe në faturë.
- Shtuar lidhja fillestare read-only me tabelën Access `Artikulli`.
- Shtuar cilësimet e MDB-së, gjenerimi TXT, draft CSV dhe dialogu i printimit.
- Shtuar workflow GitHub Actions për build Windows.
- Ruajtja reale e faturës në Access mbetet punë e ardhshme.
