PROSHITJE WPF - UPLOAD TO GITHUB

1. Extract the ZIP.
2. Upload all files INSIDE the extracted folder to the root of your GitHub repository.
3. Make sure .github/workflows/build.yml is included.
4. Commit to main or master.
5. Go to GitHub > Actions > Build ProShitje WPF x86.
6. When successful, download artifact ProShitjeWpf-Windows-x86.

Important: this is a development prototype. F6 still saves a local CSV draft and does not save invoices to the Access sales tables. Do not use for live sales until database invoice saving, stock, points, and fiscal output have been implemented and tested.
